# 单通道Rrs比对-功能说明书

本文档详细说明了 `IES-SpecCheck` 上位机中“单通道Rrs比对”功能的实现细节、状态流转、数据管理及特殊自动化逻辑。

## 1. 功能概述

该功能允许用户使用单个亮度探头，通过严格顺序的四步测量法（Lp1 -> Lsfc -> Lsky -> Lp2）来获取水体的遥感反射率（Rrs）。其核心机制是利用同一探头在相同积分时间下的比值运算来抵消系统响应函数，从而实现无需绝对辐射定标的Rrs测量。

主要功能为：

- **单通道物理量计算Rrs**: 系统支持并优先推荐使用物理量（Radiance）进行比对。
  - 注：只有在探头具备波长和辐值标定信息且用户开启选项时，才启用物理量计算。

- **单通道DN值计算Rrs**: 系统支持使用DN值（Radiance）进行比对。
  - 注1：不具备波长标定信息的，则按码值序号作为X轴，该探头的Rrs会被计算，但不会被展示(以避免由于坐标轴不对齐问题造成图标污染)
  - 注2：可通过保存文件的方式记录所有采集和计算的DN光谱及Rrs，如果不具备波长标定信息，则第二行的wavelength为空
  - 注3：记录该Rrs的文件不会包含'DN'字样。

- **比对逻辑分离**:
  - **主图表区**: 仅展示 **物理量** 光谱（Es, Lw, Lp, Lsfc, Lsky）和最终的 **Rrs**。
  - **DN值查看器**: 一个独立、可折叠或弹出的区域，用于查看所有探头的原始 DN 值曲线。这对于诊断未标定探头的信号质量非常有用，且默认关闭以节省资源。
- **混合模式**: 系统支持在一个比对会话中混合使用“仅支持DN”的探头和“支持物理量”的探头。Rrs 结果将总是被计算和展示（因为 Rrs 是比值，DN计算和物理量计算在理论上等效，前提是积分时间一致）。

## 2. 核心状态机

为了确保测量的物理严谨性和数据一致性，每个测量组（Group）的交互逻辑由一个严格的状态机控制。详细状态定义请参考 `单通道Rrs比对-状态机设计规范.md`。

## 3. 自动化与特殊逻辑

本功能包含两个高级自动化开关，极大地简化了用户操作并增强了数据安全性。

### 3.1 自动优化积分时间并锁定

- **默认状态**: 开启 (`True`)
- **行为逻辑**:
  - 在探头配置界面，有个自动优化积分时间的开关，对于在DN模式下的探头，系统会在用户**`第一步：配置探头测量组`**点击**`下一步`**按钮进入**`第二步：测量与计算`**后，自动开始对这些探头进行积分时间优化，优化完成后自动锁定该积分时间；
  - 积分时间优化逻辑：采集光谱，连续出现3次积分时间相同，则视为优化完成，当前光场稳定且积分时间不变。

### 3.2 自动计算开关

- **默认状态**: 开启 (`True`)
- **行为逻辑**:
  - 当用户完成第四步采集（Lp2）时，程序会立即自动触发 `calculate_rrs` 流程。
  - 如果用户觉得最后一次采集不理想，点击“重新采集 Lp2”，采集完成后，程序会自动**重新计算** Es 和 Rrs，无需用户再次点击计算按钮。
  - **优势**: 实现了“采集即得结果”的流畅体验。

### 3.3 自动保存开关

- **默认状态**: 开启 (`True`)
- **核心区别**:
  - **手动保存**: 只有在所有步骤完成且计算出结果后，用户才能点击“保存本次数据”。这样保存可以确保拿到的数据集是一个完整的数据集。
  - **自动保存**:
    - **增量式写入**: 只要开启此开关，每当用户点击采集（如 Lp1），数据就会立即被追加写入到 CSV 文件中。
    - **容灾能力**: 即使软件崩溃、断电或用户中途决定清空重来，**之前采集的原始数据（Lp1, Lsfc等）已经安全地保存在硬盘上**。
    - **文件系统视角**: 在文件系统中，这可能表现为一个“不完整”的 Session 文件夹（例如只有 `Lp1` 和 `Lsfc`的csv文件）。这被视为一种**特性**而非缺陷，允许用户在异常情况下找回已测量的数据。

## 4. 数据可视化策略

为了解决DN值与物理量混淆的问题，绘图逻辑进行了严格分离。

### 4.1 配置选项：使用物理量

在配置测量组时，新增一个勾选框 **“使用物理量计算”**。

- **可见性**: 仅当所选探头类型为 Radiance 且系统检测到该探头具备标定参数（如 TriOS 的 `.ini` 或 上位机的标定表中存在该 OCR 的辐值标定信息）时，此选项才可用（Enabled）。否则禁用并提示“该探头无标定信息”。
- **默认值**: 如果探头支持，默认为 `True`；否则为 `False`。

### 4.2 主图表区 (物理量 & Rrs)

此区域默认显示，用于科学比对。

- **Rrs (遥感反射率)**:
  - **内容**: 显示 **所有** 已完成计算的测量组的 Rrs 曲线 (没有波长标定系数的探头除外)。
  - **逻辑**: 无论探头是否使用物理量计算，Rrs 作为比值（$Rrs \approx \frac{L_w}{E_s}$）在理论上是一致的。
- **物理量光谱图 (Es, Lw, Lp, Lsfc, Lsky)**:
  - **内容**: 仅显示 **勾选了“使用物理量计算”** 的探头数据。
  - **逻辑**: 未勾选或不支持物理量的探头，其数据将**不会**出现在这些图表中，避免量纲不同的曲线（DN vs mW/m²）出现在同一坐标系中。

### 4.3 DN值查看器 (独立监视器)

为了性能优化和界面整洁，原始信号监视被移至独立区域。

- **UI入口**: 在探头积分时间控制界面上方有个的配置栏中有个 **“显示 DN 监视器”** 开关。
- **默认状态**: 关闭/隐藏。
- **布局**: 在当前UI的Body下渲染 5 张图表，分为两行：
  - 第一行: `Lp (Panel DN)`, `Lsky (Sky DN)`, `Lsfc (Water DN)`
  - 第二行: `Es (Calculated DN)`, `Lw (Calculated DN)`
- **内容**: 绘制 **对应探头** 测量组的 DN 数据。
- **特殊标注**: 对于不支持物理量的探头，在图例名称后添加 `(仅DN)` 标识。
- **性能优化**: 当查看器关闭时，相关 Plotly 图表对象应被注销或清空，UI元素也一并清除，避免后台渲染占用 CPU/内存。

## 5. 数据管理与存储 (V2.0 新增)

### 5.1 文件结构

所有数据存储在 `output/single_channel_rrs/` 目录下，按 Session 进行组织。

- **Session 目录**: `session_{YYYYMMDD}_{HHMMSS}/`

### 5.2 文件命名规则

为了清晰区分物理量数据和原始 DN 数据，文件名规则严格如下：

1. **物理量数据 (PHY)**
   - **条件**: 仅当该组启用了“使用物理量计算”时生成。
   - **规则**: **不带后缀**。
   - **格式**: `group{ID}_{Type}_{ProbeType}-{SN}_{Timestamp}.csv`
   - **示例**: `group1_Lp1_TriOS-86BB_20231121_123000.csv`
   - **注意**: $Rrs$固定为这种格式，即使该Rrs是在DN模式下计算的。
2. **DN 值数据 (DN)**
   - **条件**: 总是生成（作为原始凭证）。
   - **规则**: 必须包含 `_DN` 后缀。
   - **格式**: `group{ID}_{Type}_{ProbeType}-{SN}_DN_{Timestamp}.csv`
   - **示例**: `group1_Lp1_OCR-25K00412_DN_20231121_123000.csv`

### 5.3 数据类型映射表

| 内部变量     | 文件类型标识 (Type) | 说明                  |
| ------------ | ------------------- | --------------------- |
| `lp1`        | `Lp1`               | 第一次测试灰板        |
| `lsfc`       | `Lsfc`              | 水面                  |
| `lsky`       | `Lsky`              | 天空                  |
| `lp2`        | `Lp2`               | 第二次测试灰板        |
| `es_result`  | `Es`                | 下行辐照度 (DN或PHY)  |
| `lw_result`  | `Lw`                | 离水辐亮度 (DN或PHY)  |
| `rrs_result` | `Rrs`               | 遥感反射率 (标准格式) |
| `lsfc_mean`  | `Lsfc_mean`         | Lsfc 的平均光谱       |
| `lsky_mean`  | `Lsky_mean`         | Lsky 的平均光谱       |

## 6. 默认配置与参数

- **默认 ρ (rho)**: 0.028 (用户可修改)
- **使用物理量**: 默认为 `False` (需用户手动开启或自动检测后开启)。
- **积分时间**: 默认为空，必须先进行“自动优化”或手动输入并锁定（物理量模式下无需锁定，使用自动积分）。
- **目标探头DN偏置**:
  - **用途**: 专门针对 **OCR 探头** 的硬件特性。OCR 探头输出的 DN 值通常带有一个固定的偏置（Offset），如果不扣除，直接用于计算比值会导致 Rrs 结果错误。
  - **配置位置**: 在每个测量组的配置卡片中，如果选择了 OCR 类型的探头，应显示此配置项。
  - **默认值**: **1000**。
  - **行为**: 在进行 Rrs 计算（无论是 DN 模式还是 Phy 模式下的 DN 监控计算）之前，系统会先从采集到的原始 DN 值中减去此偏置。
