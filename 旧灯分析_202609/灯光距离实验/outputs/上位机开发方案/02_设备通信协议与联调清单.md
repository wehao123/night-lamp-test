## 2 共用 RTU 封包规则

请求中的地址、功能码及数据是二进制字节。例如 `FE` 是 1 个字节，不是 ASCII 字符 F 和 E。RTU 不追加 CRLF；表中现成帧已含 CRC，不重复追加。

CRC16/Modbus 初值 0xFFFF，多项式反向表示 0xA001，逐字节计算，发送低字节在前。寄存器内字节高位在前；跨寄存器的 32 位字序必须按设备手册单独处理。

03 响应一般为 `地址 03 字节数 数据 CRC低 CRC高`，总长 `字节数+5`。异常响应为 `地址 (原功能码|80) 异常码 CRC低 CRC高`，总长 5。应验证预期地址、功能、数据长度及校验，再进行数值换算。

标准 Modbus 广播地址为 0，普通单播地址为 1～247，见[Modbus 官方串行规范](https://modbus.org/docs/Modbus_over_serial_line_V1_02.pdf)。本继电器的 FE 是厂家扩展行为，不能当作标准广播的通用处理方式；FE 请求会有手册规定的回复。

## 3 LH-IO204 继电器

### 3.1 已记录基础命令

依据 S2、S4 的协议说明和例程；以下五条 CRC 已用本地程序重新计算并通过。

| 功能 | 完整 HEX | 期望响应 |
| --- | --- | --- |
| CH1 开 | FE 05 00 00 FF 00 98 35 | 与请求相同的 8 字节 |
| CH1 关 | FE 05 00 00 00 00 D9 C5 | 与请求相同的 8 字节 |
| CH2 开 | FE 05 00 01 FF 00 C9 F5 | 与请求相同的 8 字节 |
| CH2 关 | FE 05 00 01 00 00 88 05 | 与请求相同的 8 字节 |
| 读两路输出 | FE 01 00 00 00 02 A9 C4 | FE 01 01 SS CRC低 CRC高，共 6 字节 |

`SS & 0x01` 为 CH1，`SS & 0x02` 为 CH2。SS=00 表示全关，01 表示仅 CH1，02 表示仅 CH2，03 表示全开。状态查询返回的是线圈逻辑状态，不证明每个负载实际通电。

### 3.2 FE 地址的现场整改点

S4 PDF 第 29 页（印刷页 28）明确说明厂家广播地址用于单设备测试，多设备总线应使用不同地址。S2 又记录继电器与电量模块共用 4001 并使用 FE，因此存在需要联调核验的差异。

保留 FE 作为现有调试配置的事实记录；正式配置应取得继电器真实单播地址，与电量模块 2 不冲突，验证后重新生成 CRC。不要自行假定继电器地址为 1，也不要自动改址。现有电量模块是否响应 FE 不能靠一般 Modbus 常识推断。

工作模式亦需核验为所需的 Modbus 控制模式，避免误用手册中的互控/主动上传模式。日常流程只提供开、关和查询，不自动执行地址、波特率和出厂设置写入。

## 4 ZH 电压电流模块

### 4.1 量程与寄存器

照片铭牌可读为 ZH-44023D-14D3、30V×5A DC；作为候选现场量程登记，仍需核对实物、接线和量程系数。S5 第 3 页说明组合型第一通道为电压，第二通道为电流。

| 地址 | 数据类型 | 含义及换算 |
| --- | --- | --- |
| 0000 | uint16 | 通道 1，`D×电压量程/10000` |
| 0001 | uint16 | 通道 2，`D×电流量程/10000` |
| 0002、0003 | 各 uint16 | 通道最大值；默认读取后清零，受 005F 配置影响 |
| 0004 | uint16 | 功率，`D×电压量程×电流量程/10000` |
| 0005～0006 | uint32 | 通道 1 高精度值，换算受 0053 影响 |
| 0007～0008 | uint32 | 通道 2 高精度值，换算受 0054 影响 |
| 0009～000A、000B～000C | 各 int32 | 双极性高精度值，补码，换算模式需匹配 |
| 0011、0012 | 各 int16 | 双极性值，`D×量程/10000` |
| 0053、0054 | 各 uint16 | 两通道量程系数，影响 32 位输出；只读核验，不随意改写 |
| 3000～3001、3002～3003 | 各 float32 | IEEE754，高字节在前；需已正确设置量程系数 |

依据 S5 第 6～9 页。无符号 16 位的实际编码范围为 0～65535；手册把范围上限写作 65536，不应照此允许溢出。

### 4.2 读取命令及响应布局

S2 记录已验证命令：`02 03 00 00 00 09 85 FF`。本次重新验证 CRC 正确。

响应为 `02 03 12 [18字节数据] CRC低 CRC高`，总长 23 字节。下表偏移从数据区第一个字节开始计数：

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 2 | U16 |
| 2 | 2 | I16 |
| 4 | 2 | Umax16 |
| 6 | 2 | Imax16 |
| 8 | 2 | P16 |
| 10 | 4 | U32 |
| 14 | 4 | I32 |

按手册高位在前的表示实现整数拼接，再用已知输入核验跨寄存器字序。16 位读取解析无符号整数；极性寄存器才使用有符号整数。

注意整段读取包含 0002/0003，会影响最大值记录。若需保留最大值采集窗口，正常轮询可分开读当前值和功率/高精度值，最大值另设计划读取。

| 用途 | HEX |
| --- | --- |
| 只读 U16/I16 | 02 03 00 00 00 02 C4 38 |
| 读功率和 U32/I32 | 02 03 00 04 00 05 C4 3B |
| 读两通道量程系数 | 02 03 00 53 00 02 34 29 |

### 4.3 32 位换算不可只保留一种公式

S5 第 7 页分别描述：

* 原始比例方式：`X = D32 × 量程 / 100000`。
* 当量程系数寄存器设置为对应铭牌值后：2～9 对应除以 100000，10～99 对应除以 10000，100～999 对应除以 1000，1000～5000 对应除以 100。

例如确认采用后者且系数为 30V、5A 时，电压为 `D_U32/10000`，电流为 `D_I32/100000`。不能再额外乘以 30 或 5。对于系数为 0/1 或超出表述范围的情况，不自行外推规则，需询问厂家并对照 16 位读值和已知输入。

建议配置项保存 `range_voltage`、`range_current`、`range_register_values`、`scaling_mode`、`word_order`、`verified_at`。模式未验证时可先使用已核准量程的 16 位物理量，32 位显示原始值和“待验证”。

离线验算例子（非现场记录）：假设量程 30V/5A，U16=8000，则 24V；I16=5000，则 2.5A；P16=4000，则 60W。原始比例方式 U32=80000 对应 24V；系数方式 U32=240000 对应 24V。这两个不同编码都可能表示同一电压，错误模式会产生看似合理但实际错误的数值。

| 查询 | 已记录 HEX | 预期 |
| --- | --- | --- |
| 设备类型 | 28 03 20 01 00 01 D9 F3 | 28 03 02 0B 01 CRC低 CRC高，依据 S2 |
| 距离 | 28 03 20 02 00 02 69 F2 | 28 03 04 D0 D1 D2 D3 CRC低 CRC高 |

两条 CRC 本次离线复核通过。距离起始寄存器为 0x2002，数量为 2，响应总长 9 字节。

仍缺字段类型（uint32、int32 或 float32）、字节/字序、米/毫米等单位、比例系数、无效值/失波码、距离与液位定义。开发时先校验并保存 4 字节，不能默认“大端浮点米”或“整数毫米”。获得协议后用至少两个已知距离及一个无效回波情形核验。

历史改址命令不纳入启动流程。软件显示地址时同时显示 `40 (0x28)`。

## 7 OCR 光谱与辐照度探头

以下为目录内 OCR V1.0 协议定义。现场探头是否就是此版本尚未确认；历史 DB 有 8 位 OCR SN，而协议二进制结构的 SN 字段只有 4 字节，因此不能用历史库的长 SN 直接改变帧长。先读取实际配置并抓取一帧，再绑定版本化解析器。

### 7.1 命令列表

命令按 ASCII 编码，尾部为 `\r\n`（HEX 0D 0A）。RTU 的“不得加回车换行”不适用于这里。

| 功能 | 命令文本 | 说明 |
| --- | --- | --- |
| 通信测试 | BAH | 预期回 AH |
| 进入命令模式/查配置 | C | 可能改变自动采集状态，需由会话管理器串行执行 |
| 查标定信息 | CAL | 类型、SN、单位、波长系数等 |
| 亮谱 DN，二进制 | SBL 256000 | 积分时间单位 μs；例子为 256ms，不是固定实验推荐值 |
| 暗谱 DN，二进制 | SBD 256000 | 同积分暗谱；验证现场快门能力 |
| 去暗 DN，二进制 | SBN 256000 | 若用于定量，需确认内部扣暗及负值语义 |
| 物理量，二进制 | SBP | 需有效辐射定标和已确认单位 |
| 亮谱/暗谱 ASCII | SAL 256000 / SAD 256000 | 便于初次联调及与二进制结果比对 |
| 物理量 ASCII | SAP | 需检查数组点数、物理量身份 |

SBL/SBD 参数按采集指令携带，不必另发不存在的“设置积分时间”命令。自动模式可能屏蔽多数命令，首版采用命令模式逐次采集。文档的 `SET LOG_LEVLE` 示例与关键字 `LOG_LEVEL` 拼写不一致，不能直接照抄；先验证固件支持的写法。

### 7.2 DN 二进制帧

依据 S7 的 C 结构，数据体 596 字节，再加 1 字节累加和和 2 字节 CRLF，共 599 字节。下表为从帧首起的零基字节偏移。

| 偏移 | 长度 | 类型 | 含义 |
| --- | --- | --- | --- |
| 0 | 4 | ASCII | WHSR |
| 4 | 3 | ASCII | HSL 辐亮度 / HSE 辐照度 |
| 7 | 4 | ASCII | 协议中的短 SN 字段 |
| 11 | 1 | ASCII | L 亮谱 / D 暗谱 / N 去暗 |
| 12 | 1 | uint8 | 帧序号，存在回绕 |
| 13 | 3 | bytes | 保留字节 |
| 16 | 4 | uint32 little-endian | 实际积分时间 μs |
| 20 | 576 | 288 × uint16 little-endian | 光谱 DN |
| 596 | 1 | uint8 | `sum(frame[0:596]) & 0xFF` |
| 597 | 2 | bytes | 0D 0A |

建议在该版本核验后使用数据体格式 `<4s3s4scB3xI288H`。S7 中的 Python 示例使用 `288h` 和有符号序号/积分时间，与结构体的无符号定义不一致；必须按字段语义修正。去暗 N 帧如果需要表达负数，应另与固件确认，首版优先存原始 L/D 并在主机端以浮点或足够宽的有符号类型相减，避免 uint16 相减下溢。

### 7.3 物理量二进制帧

数据体 1168 字节，完整帧 1171 字节：0～10 字节与上表的头部/类型/SN 相同；11 字节为 uint8 帧号；12～15 为保留字段；16～1167 为 288 个 little-endian float32；1168 为累加和；1169～1170 为 CRLF。

可用数据体格式 `<4s3s4sB4x288f`。拒绝或标记 NaN/Inf；单位来自对应设备的 CAL/配置及有效校准，不根据曲线外观猜测。此结构没有积分时间字段，不能把主机请求值无条件当作设备实际积分时间。

文档虽把校验称作“crc8”，实际算法为逐字节求和取低 8 位，不是多项式 CRC-8；命名建议使用 `checksum_sum8`。

### 7.4 流式解析

先根据已确认的协议版本和待响应命令选择帧格式，识别 WHSR、检查预期长度、尾标志和累加和，成功后再解码。保留未完成帧；连续到达的多个帧逐个出队。文本日志单独归档，不混入二进制数组。

DARK_COUNT/LIGHT_COUNT 设置可能使一次采集涉及多个亮暗帧，不能收到第一帧就假定事务完成。心跳、配置查询和采集共用设备锁，采集期间不插入保活命令。文档里的“3 秒 + 积分时间”只作为起始超时策略，需按实际多帧行为调整。

波长映射来自对应 SN 的系数；配置文件 `start_index=1` 提示需要确认多项式像元索引起点，不能随意从 0 代入。不同探头的波长网格如不一致，先在共同有效标定范围内对齐，禁止外推。

## 8 联调记录模板

每台设备至少保存一套以下记录，作为驱动验收样例：

| 字段 | 填写要求 |
| --- | --- |
| 身份 | 型号、SN、固件、协议版本、手册名称和页码 |
| 连接 | IP、端口、下游串口格式、地址、连接时间 |
| 供电 | CH1/CH2 状态、开机后等待时长 |
| TX/RX | 原始 HEX；ASCII 命令同时保留可读文本；包含校验与尾符 |
| 时间 | 请求发出、首字节到达、完整帧到达、设备测量时刻如有 |
| 解析 | 偏移、数据类型、字节序、原始整数/浮点、缩放、单位、质量码 |
| 对照 | 厂家软件读数或可靠参考值，测量条件与时间差 |
| 结论 | 已通过/未通过/待补证据；经办人及日期 |

验收样例应包含正常帧、坏校验、错地址、异常响应、超时、分包、粘包和迟到帧。光谱增加高 DN、序号回绕、长积分和快门暗谱；雷达增加失波；水质增加未装传感器/清洗状态；电量增加不同缩放配置。
