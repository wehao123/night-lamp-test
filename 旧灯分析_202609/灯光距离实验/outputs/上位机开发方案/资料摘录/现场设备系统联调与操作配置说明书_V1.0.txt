1. 系统最终结构
本系统采用 192.168.2.0/24 局域网，E810 将 4 路串口分别映射为 TCP Server 端口。最终端口分配避免了同一逻辑串口同时独立使用 RS232 与 RS485 的冲突。
PC 192.168.2.100        │ Ethernet        ▼R300S LAN / Gateway 192.168.2.1        │        ▼E810-DTU 192.168.2.10 ├─ Port 1 / RS485 / TCP 4001 → 继电器 + 电压电流采集模块(ID=02) ├─ Port 2 / RS485 / TCP 4002 → MPA-6S 水质仪 + MIK-WSR201 雷达(ID=40) ├─ Port 3 / RS232 / TCP 4003 → 亮度计/辐亮度探头 └─ Port 4 / RS232 / TCP 4004 → 照度计
串口原则：E810 的每个编号端口是一个逻辑 UART。最终配置中：Port 1/2 专用于 RS485，Port 3/4 专用于 RS232；不要再把同一编号端口的 RS232 与 RS485 当作两个独立通道同时运行。

3. 供电与继电器控制
3.1 最终供电分配
控制系统基础设备（路由器 / E810 / 继电器本体）→ 保持常供电继电器 CH1 → 仅控制电压电流采集模块电源继电器 CH2 → 控制其余现场设备/负载              （水质仪、雷达、亮度计、照度计、搜索灯、相机等按现场接线）
联动现象：CH1 关闭后，电压电流采集模块无回复属于正常；CH2 关闭后，水质仪、雷达、亮度计、照度计等无回复也属于正常。

3.2 继电器通信与常用命令
继电器位于 E810 Port 1 的 RS485 总线上，默认通信格式为 9600 / N / 8 / 1，现场使用广播地址 FE 进行控制。网络调试助手连接 192.168.2.10:4001，选择 HEX 发送/HEX 显示，不追加回车换行，不额外计算 CRC。

5. Port 2：MPA-6S 水质仪 + MIK-WSR201 雷达
5.1 共用 RS485 总线
E810 Port 2 A ─┬─ MPA-6S A                └─ MIK-WSR201 AE810 Port 2 B ─┬─ MPA-6S B                └─ MIK-WSR201 BPort 2：9600 / 8N1 / TCP Server 4002
MPA-6S 使用 RS485 Modbus RTU；雷达在现场已改为 Modbus 地址 40（十六进制 0x28）。水质上位机通常搜索 1~32，因此雷达地址 40 可避开水质软件的常规扫描范围。
多主站注意：水质上位机、网络调试助手、其他程序不要同时持续向同一 Port 2 总线发送命令。E810 可以接受多个 TCP Client，但 RS485 总线仍需要避免两个主站同时发包造成碰撞。

7. 推荐日常操作流程
7.1 开机与设备上电
确认 24V 主电源、R300S 独立供电、E810 与继电器本体供电正常。
电脑接入 R300S LAN，确认电脑为 192.168.2.100，能访问 192.168.2.10。
网络调试助手以 TCP Client 连接 192.168.2.10:4001。
需要电压电流采集时，发送 CH1 开：FE 05 00 00 FF 00 98 35。
需要水质、雷达、亮度、照度等设备时，发送 CH2 开：FE 05 00 01 FF 00 C9 F5。
等待现场设备稳定启动；雷达建议预留约 30~60 s，水质仪至少等待数秒。
按设备选择对应端口：Port1=4001，Port2=4002，Port3=4003，Port4=4004。
使用厂家上位机时先启动相应虚拟 COM 映射，再打开厂家软件；同一串口总线避免多个主站同时持续发指令。
7.2 关机顺序
先停止采集/保存数据，关闭厂家上位机或停止轮询。
断开 COM10 等虚拟串口的主动占用（必要时）。
发送 CH2 关：FE 05 00 01 00 00 88 05。
如不再需要电压电流模块，发送 CH1 关：FE 05 00 00 00 00 D9 C5。
确认现场负载断电后，再按需要关闭系统总电源。
8. 网络连通性快速检查
在 Windows PowerShell 中使用以下命令。端口返回 TcpTestSucceeded : True，说明 E810 对应 TCP Server 正在监听。
Test-NetConnection 192.168.2.10 -Port 4001Test-NetConnection 192.168.2.10 -Port 4002Test-NetConnection 192.168.2.10 -Port 4003Test-NetConnection 192.168.2.10 -Port 4004
如果当前窗口是 CMD，可用：
powershell -Command "Test-NetConnection 192.168.2.10 -Port 4002"
