# 二代 OCR 模组室内实验分析报告

**探头型号**：OCR-25F02100-1　**标定 ID**：1　**采集日期**：2026-09-20　**报告日期**：2026-09-23

**实验范围**：积分时间线性度（实验 B / 5.7.7）、信噪比（实验 C / 5.7.8）、弱光表现（实验 D / 5.7.11）

**数据规模**：线性度 12 份 CSV、亮暗场 20 份 CSV，覆盖全部 288 个原生通道，波长 305.883–878.092 nm。全部定量结果使用原始帧，未做平滑、滤波或插值。

## 1. 结论摘要

1. **积分时间线性度合格。** 4,000–45,000 DN 区间内 1,208 个合格「通道×组」数据点，最大 |δ| 为 1.738%、最大 |γ−1| 为 1.708%。其中 25,000–35,000 DN 段表现最优，δ 中位数 +0.226%、|δ| 95 分位 0.557%。

2. **信噪比中段充裕，但非全波段达标。** 10 个已测条件的逐波长 SNR 中位数为 95.1–191.3，中位数全部高于判据线 20。但中位数不代表逐通道：最低已测条件 60V/64ms 仍有 53/288 个通道 SNR<20（主要在短波端），60V/128ms 为 24/288。最优条件 72V/64ms 下 288 个通道 SNR 全部 ≥20 且无码值超限。

3. **弱光方面，已测范围内表现良好，但不能外推为"始终达标"或给出可靠的 Lmin。** 最低已测亮度档 60V 下中段（500–800nm）SNR 中位数为 122.7（64ms），仍高于判据线。按此中段标度关系外推，理论上信号再降约 19 倍才会使中段 SNR 中位数降至判据线 —— 但这是**基于 5 个数据点、外推到远低于实测范围（669 DN vs 实测最低 12,864 DN）的探索性估算**，使用的是波段中位数而非逐通道结果，且已知降压会改变谱形（5.1 节），不能保证外推位置下全部输出波段逐通道达标，也不能作为最低可测亮度 Lmin 或验收结论。

4. **全波段单档覆盖在当前光源与仪器组合下有困难。** 实测响应在 663 nm 附近远高于 420 nm 以下波段（约 28 倍），单一积分时间无法同时满足两端的码值余量与信噪比要求。这一差异由光源光谱、光路透过率、探测器逐波长响应共同决定，现有数据不能将其单独归因于光源或排除仪器因素。已按条件给出推荐参数与可用波段。

5. **高信噪比不能替代码值余量检查。** 76V/64ms 条件下 288 个通道 SNR 全部达标，但扣除固定偏置后，584.8–745.3 nm 的 78 个通道实际亮值超过 80% 满量程（原始导出值最高 60,729 DN）。同电压改用 32ms 后超限归零，工作候选通道由 199 增至 264。

## 2. 数据与预处理

### 2.1 采集模式与偏置

依据 `标定上位机V3/doc/sensor/OCR协议.md`、`K值计算机制说明.md`，并经设备侧同事（郝威、李阳，2026-09-23）确认：

| 标识 | 含义 | 本报告处理方式 |
| --- | --- | --- |
| L | 全光码值，含暗值 | 逐帧减去同条件平均暗谱 |
| D | 遮光采集的暗值 | 计算暗均值、暗标准差与暗漂移 |
| N | 设备内部已完成 N=L−D 处理后的码值 | 仅扣偏置 1000 DN，不再减独立暗场 |

**L、D、N 三者导出时均额外叠加了固定偏置 1000 DN**（设备侧已确认），用于避免 uint16 码值在（暗电流 > 亮场信号）时下溢为 0。计算式：

```
线性度（N 模式）：  Sᵢ(λ) = Nᵢ(λ) − 1000
信噪比（L/D 模式）：D̄(λ) = ΣDⱼ(λ)/n_D；Sᵢ(λ) = Lᵢ(λ) − D̄(λ)
```

信噪比一侧的 L、D 各自都带着同一个 +1000，相减时该偏置自动抵消（(L_真+1000)−(D_真+1000) = L_真−D_真），**因此第 4、5 节的净信号、SNR、CV 计算不受此偏置影响，无需额外处理**。满量程判据（4.1 节）需先扣除该偏置再与阈值比较，实施细节见 4.1 节脚注。

线性度文件夹全部为 N 模式，因此无配套暗场文件（该步骤在协议中已注明不需要测）；信噪比文件夹为 L/D 成对采集。

**暗场数值的对照**：信噪比文件夹实测的暗均值为 9,174–9,514 DN（4.4 节），扣除已确认的 1,000 DN 固定偏置后为 8,174–8,514 DN，量级与《IES 模组光电响应非线性物理机制与系统分析报告》记载的"典型 DDN 约 8,000"接近。但该文档针对的是另一型号探测器（Hamamatsu C12880MA），且本报告测得的暗场信号可能还包含电路基线等成分，未做温度/积分时间扫描以分离暗电流与其他底噪来源，**此处仅作数量级对照，不构成独立的交叉验证**。

## 3. 实验 B：积分时间相对线性度

**目的**：确定光谱仪在不同积分时间下的线性工作区。同一光照条件下，理想情况下信号应随积分时间等比例增长（曝光时间翻倍，读数也该翻倍）；本实验通过成对比较不同积分时间的实测结果，检验这一比例关系在多大码值范围内成立、哪里开始偏离，为后续实验和实际使用时选择积分时间提供依据。

### 3.1 方法

固定光源、光路与采集设置，同一波长处理想净光应随积分时间成正比。以短积分为参考推算长积分应测到的信号，再与实测比较：

```
理想响应：      S(λ,t) = k(λ)·E(λ)·t
长积分理论值：  S_理论,长(λ) = S̄_短(λ) · t_长/t_短
非线性比值：    γ(λ) = S_理论,长(λ) / S̄_长(λ)
实测相对理论：  δ(λ) = (S̄_长 − S_理论,长)/S_理论,长 × 100% = (1/γ − 1) × 100%
```

γ 与 δ 分母不同、符号相反，统计统一采用 δ。本方法不需要入射光的绝对数值，但依赖其在长短积分之间保持稳定；两次采集非同步且无同步亮度记录，整体偏差可能包含光源变化。

**统计门槛**：长短积分净光均为正，且两档逐帧 SNR 均 ≥ 20。未达门槛的通道保留在逐通道数据中，但不计入统计。

**得到的数据**：本实验共 6 组倍频配对（32→64ms、64→128ms 各配 3W/4W/5W 三档）。每组内 288 个通道各算出一对 γ、δ 值，即每组产出 288 行「通道—码值—γ—δ」的逐通道数据，6 组合计约 1,728 行。图 1 是把这 1,728 个点按组着色画在一张散点图上；表格部分先给每组的汇总统计（3.2 节），再把六组的通道级数据按码值大小重新分箱汇总（3.3 节）。

将 288 通道按 310–400 / 400–480 / 480–560 / 560–878 nm 分为四段重新着色后（图 3），各段散点在 γ–码值平面上目视重叠，未见明显的系统性错位，与《IES 非线性分析》7.1 节的观察方向一致。

## 4. 实验 C：信噪比

**目的**：评估不同亮度、积分时间组合下，光谱仪逐波长的重复噪声水平。同一条件下多次重复测量，看读数抖动有多大，从而确定哪些波长在哪些参数下的测量结果足够稳定可用；同时检查是否存在满量程超限、采集过程中信号漂移等会影响可用性的问题。

### 4.1 方法

沿重复帧方向（非沿波长方向）计算：

```
S̄(λ) = ΣSᵢ(λ)/n_L
s_S(λ) = √[Σ(Sᵢ(λ)−S̄(λ))²/(n_L−1)]
SNR(λ) = S̄(λ)/s_S(λ)
CV(λ)  = s_S(λ)/|S̄(λ)| × 100%
```

正信号下 CV = 100%/SNR，故「SNR≥20」与「CV≤5%」是同一重复性要求的两种表达，非两份独立证据。减去固定暗均值不改变亮值帧间标准差，主 SNR 不将暗标准差计入分母，也不乘 √n 报告均值的 SNR。

**补充判据**：

```
码值余量：每通道 max(原始亮值 Lᵢ) − 1000 ≤ 0.8 × 65535 = 52,428 DN
采集期漂移：Sᵢ(λ) ≈ a + k·τᵢ  →  D_fit = k·(τ_末−τ_首)/|S̄| × 100%，要求 |D_fit| ≤ 2%
```

码值余量判据使用原始亮值而非净光值，但需先扣除 L 导出值中固定叠加的 1,000 DN 偏置（2.1 节），再与 80% 阈值比较 —— 该偏置是设备为避免 uint16 下溢而人为添加的常量，不代表真实光信号，若不扣除会把不属于光信号的部分计入满量程占用，结果偏保守。漂移按实际时间戳拟合首尾变化，不等同于峰峰变化。

### 4.2 分层判据

| 工作候选 | 基本重复性 + 原始码值 ≤80% 量程 + \|D_fit\| ≤2% |
| 推荐候选 | 推荐重复性 + 同样两项 |

**76V/64ms 说明**：该条件 SNR 表现最优（中位 191.3，全通道 ≥20），但扣除固定偏置后，584.8–745.3 nm 一带的 78 个通道实际亮值仍超过 80% 满量程，原始导出值最高 60,729 DN。全部亮帧均未达 65,535，但无数字截顶不等于无软饱和。经码值与漂移筛选后工作候选通道降至 199。同电压改用 32ms 后超限归零、工作候选回升至 264，属参数选择问题。

### 4.4 暗场统计

各条件暗场均值中位数 9,174–9,514 DN，帧间标准差中位数 31.5–35.0 DN。扣除已确认的 1,000 DN 固定偏置后，真实暗电流约为 8,174–8,514 DN，与参考文档记载的"典型 DDN 约 8,000"基本一致（见 2.1 节）。暗标准差包含多种噪声与漂移，不能称为纯读出噪声。

## 5. 实验 D：弱光表现

**目的**：了解光谱仪在光照逐渐变暗时的表现——哪些波长还能用、延长积分时间能不能顶上去、以及理想情况下能测到多暗，为夜间实测提供"能不能测、怎么测"的参考依据。本次以降低光源电压模拟变暗，未测到失效边界，详见各小节说明。

### 5.1 口径说明

本次以五档电压改变光源，64ms 覆盖全部电压，适合同积分时间横向比较。

缺少实测参考板辐亮度与透过率记录，**不能将电压比当作辐亮度比**，也不能认为降压是光谱各处同比例减弱 —— 实测 60V 相对 72V 的谱形角约 6.4°、NRMSE 约 11.7%。本节所有结论均以电压档为自变量表述。

### 5.2 延长积分时间的效果

```
逐波长 SNR 增益：G(λ) = SNR_长(λ)/SNR_短(λ)
单位时间响应比：Q(λ) = [S̄_长/t_长] / [S̄_短/t_短]
```

| 电压 | 积分时间变化 | G 中位数 | SNR≥20 通道增加 | Q 中位数 |
| --- | --- | --- | --- | --- |
| 60V | 64→128 ms | 1.516 | +29 | 1.00515 |
| 63V | 64→128 ms | 1.527 | +38 | 1.00210 |
| 68V | 32→64 ms | 1.508 | +37 | 1.00617 |
| 72V | 32→64 ms | 1.510 | +28 | 1.00430 |
| 76V | 32→64 ms | 1.554 | +17 | 0.99777 |

G 中位数为逐波长增益的中位数，不等于两个全谱 SNR 中位数的商。各档集中在 1.51–1.55，说明时间加倍带来的重复性改善明显，但并非每个通道按同一倍数增加。Q 接近 1 表示单位时间响应基本一致；76V 的 Q 中位数 0.998 略低于 1，与强信号区响应压缩表现相符，单凭该项不足以完成器件归因。

### 5.4 弱光余量估算

固定 64ms，取 500–800 nm 中段通道的信号与 SNR 中位数：

| 电压 | 中段信号中位 DN | 中段 SNR 中位 |
| --- | --- | --- |
| 60V | 12,864 | 122.7 |
| 63V | 17,337 | 140.4 |
| 68V | 25,785 | 168.9 |
| 72V | 34,717 | 210.8 |
| 76V | 44,319 | 262.1 |

拟合得 **SNR ∝ 信号^0.601**（0.5 对应散粒噪声主导，1.0 对应读出噪声主导）。外推至 SNR=20 对应信号约 669 DN，为最低已测档（60V/64ms，12,864 DN）的 1/19.2。

**本节为探索性外推，未经低信号条件下的实测验证，不构成最低可测亮度结论**，理由：

1. 拟合仅基于 5 个数据点（60–76V），外推位置（669 DN）远低于全部实测点（12,864–44,319 DN），属外插而非内插；
2. 使用的是 500–800 nm 中段的信号与 SNR **中位数**，不代表逐通道结果，尤其不能代表短波端；
3. 降低电压会改变光谱形状（5.1 节已指出 60V 相对 72V 谱形角约 6.4°），标度关系在更低亮度下是否仍然成立未知；
4. 长积分（叠加至 2048 ms 上限）下暗电流累积、噪声模型是否仍遵循同一标度关系，本次未做验证。

因此"约 19 倍余量"仅作数量级参考，**不能据此认定最低可测亮度 Lmin，也不能直接叠加积分时间上限来推算实际弱光性能**。若需要确定 Lmin，必须在更低亮度档下实测。

### 5.5 全波段单档覆盖的限制

72V/64ms 条件下峰值 39,556 DN（663 nm），而 420 nm 以下平均仅 1,390 DN，**实测响应动态范围约 28 倍**。单一积分时间无法同时满足：延长则中间波段突破 80% 量程，缩短则两端信号不足。

该实测差异由光源光谱、光路透过率、探测器逐波长响应共同决定，现有数据不能将其单独归因于光源、也不能排除仪器自身波长响应不均的贡献；后续如需分离，需要独立的光源光谱测量或参考探测器比对。不论归因如何，标准解法都是多重积分时间融合（HDR 曝光，见《IES 非线性分析》6.2 节）：长积分获取边缘弱波段、短积分获取中间强波段，在数据层拼接。本次数据支持该方向：60V 下 128ms 相比 64ms 将工作候选段由 181 扩至 223 通道；76V 下 32ms（264 通道）优于 64ms（199 通道）。实施前需另行验证拼接处的一致性。

## 8. 室外实验衔接建议

### 8.1 现场工作窗口

| 检查项 | 合格范围 | 依据 |
| --- | --- | --- |
| 峰值原始码值 | ≤ 52,428 DN | 协议 80% 满量程判据 |
| 目标波段码值 | ≥ 10,000 DN，宜 25,000–35,000 DN | 固件有效区间下限；本次最优线性段 |
| 积分时间 | ≤ 128 ms | 本次已验证上限 |

三项同时满足时，本报告的线性度与信噪比结论直接适用。

**注意**：设备自动积分模式的目标窗口为 30,000–60,000 DN，其上限高于协议的 52,428 DN 安全线。使用自动模式后应复核峰值码值，必要时手动缩短积分时间。

### 8.2 现场采集要求

每套参数下采集三组数据：

1. **开灯、对准目标** —— 正式数据
2. **关灯、对准目标** —— 环境背景（月光、岸基照明等非本机光源贡献）
3. **遮光** —— 暗场

计算时：本机光源贡献 = 开灯 − 关灯；仪器底噪由遮光暗场给出。室外温度与暗室不同，暗电流随之变化，**不得套用室内暗场数据**。

### 8.3 需现场确认的事项

1. 自动积分模式在实际观测几何下选定的积分时间，据此判断是否落在已验证区间（≤128 ms）。
2. 目标波段在现场条件下的实际码值水平，尤其是蓝紫波段 —— 室内测试中该波段信号本就偏弱，水体离水辐射在该波段同样偏弱。
3. 水面运动带来的帧间波动。室内测试对象为静止参考板，该项未覆盖，需现场采多帧评估。
